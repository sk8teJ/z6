# Практическая работа №6 — Bootstrap 5

Учебный проект с примерами компонентов Bootstrap 5.3.3.

## Страницы
- **index.html** — горизонтальная и вертикальная формы, варианты кнопок, таблицы без границ, с границами и с цветовыми состояниями.
- **cards.html** — адаптивная сетка карточек и модальное окно с формой обратной связи.

## Структура
```text
z6/
├── index.html
├── cards.html
├── css/styles.css
├── js/app.js
└── README.md
```

## Запуск
Откройте `index.html` в браузере. Bootstrap подключается через CDN, поэтому для загрузки стилей и скриптов нужен интернет.

## Поведение JavaScript
- Проверка форм выполняется средствами HTML5.
- После проверки выводится сообщение об успешном заполнении.
- Кнопки карточек открывают Bootstrap Modal и передают в него тему выбранной карточки.
- Отправка формы демонстрационная: данные не сохраняются и не передаются на сервер.

Технологии: HTML5, CSS3, JavaScript, Bootstrap 5.3.3.
